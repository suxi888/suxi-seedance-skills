# 苏西 Seedance 提示词

把用户提供的内容改写成可执行的导演单，而不是形容词堆砌。用户的明确要求优先于本技能中的默认建议。

## 工作方式

1. 先锁定不可改变的信息：主体、目的、事件顺序、人物关系、台词、产品事实、参考图用途和用户限制。
2. 明确输入模式：
   - **纯文字**：所有场景、人物、动作和声音从文字生成。
   - **文字＋图片**：用 `@图片1`、`@图片2` 分别绑定人物、服装、产品或场景；不得写成“参考原视频”。
   - **参考视频**：只有用户实际提供视频时，才可使用 `@视频1`，并写清参考动作、镜头、声音或环境中的哪些部分。
3. 判断主类型：短剧、多人物对话、KOC/Vlog、带货、口播、穿搭、展示、变装、文旅、ASMR、3D 演示或通用导演模式。
4. 按任务需要组织八类信息：视频定义、主体与参考、环境与光线、分镜摄影、动作与表演、转场与连续性、台词与声音、结果与必要约束。
5. 把动作写成可执行链条：初始状态 → 目光 → 手部动作 → 重心变化 → 表情变化 → 结果状态 → 下一段承接。
6. 多人物必须固定左/右、前景/背景、服装特征、视线、说话轮次和进出画方向；每个人物使用独立图片锚点，禁止串脸和角色互换。
7. 有台词时嵌入对应时间段，并在结尾逐字汇总；分镜内台词与汇总不得改词、漏词或调序。
8. 输出前检查时长、动作、台词、运镜、人物位置、左右手、道具状态与参考映射是否连续且无冲突。

## 事实与参考边界

- 不编造品牌参数、价格、功效、人物身份、台词事实或产品背面结构；缺失时保留 `@占位符`。
- 多张参考图逐张说明“参考什么”和“不参考什么”。只给头像时，不声称掌握完整服装背面。
- 用户只要纯文＋图提示词时，不要求视频证据、关键帧、锚点审批或原音轨复用。
- 用户要求逐像素保留既有视频时，应说明生成式视频会重新推演画面；如果确需换人换品，改用 `$suxi-seedance-remix`。

## 输出要求

- 默认中文。
- 只输出最终提示词正文，不写方法解释、前言或无关建议。
- 简单片段保持简洁；8–15 秒可用一镜到底或少量镜头；超过模型单段上限时拆段，并重申跨段连续性。
- 详细标准见 [references/methodology.md](references/methodology.md)。复杂多人物、长视频、产品物理过程或参考图较多时必须阅读该文件。
