# suxi-seedance-skills
这个 Skill 本质上是一个 Seedance 视频提示词“导演编译器”。 它不会只给你堆“电影感、氛围感、高级感”这类形容词，而是把你的创意、脚本、台词、产品资料和参考图，整理成 Seedance 更容易执行的导演单。例如，你给我： 一个女生穿红色连衣裙，拿着香水走到镜子前，喷一下，然后说：“今天就选它。”  它不会只扩写成“高级时尚广告”，而会进一步明确： 人物从画面右侧进入 → 右手持香水 → 走到镜前停下 → 目光先看镜中自己 → 抬起右手按压喷头 → 微微闭眼 → 放下香水看向镜头 → 在指定时间说出台词。实际使用时，你只要把创意、脚本、台词、产品资料或参考图交给我，我会判断属于哪种模式，然后默认直接输出可复制进 Seedance 的最终中文提示词，不夹带多余的方法说明。
